# v6.1.0 M1〜M4 実装記録

ブランチ `feat/v6.1.0-wcde`（基点 `bba77f2` v6.0.0 released）。仕様: AlterHistory_v6_1_0_Implementation_Spec_rev1.md。テストの更新は M9（この記録の末尾に「古くなったテスト」を挙げた）。

## M1 領域契約・tick の順序
- `wcde/domains/registry.js` を全面的に書き直し: 19 領域それぞれに owns / reads / updates / emits / invariants / cadence / phase を宣言。`validateRegistry()` が所有の重なり・存在しない領域への参照・PHASES に無い位置・処理の重複を検出する（現在は違反ゼロ）。`ENTRY_PATHS` に命令の入口 4 経路（Command API／AI 行動／創造主の介入／月次 tick のトランザクション）。
- `civ/tick.js` の PHASES を仕様 §5.2 に合わせて 18 段に再定義（interventions・ecosystem・people・archive を追加）。`register(phase, fn, label, {every, offset})` で領域ごとの更新頻度を持てる。**every の判定は、時計が月を進めたあとの monthIndex で行う**（最初の実装は進める前の値を見ていて、国家形成・経済・政治・軍事が一度も走らなかった。直した）。
- `wcde/contract.js` に 4 経路の契約を明文化。`defineCommand` に領域（domain）を付け、`commandTable()` で一覧できる。
- 文書は `node scripts/gen-v61-docs.mjs` で台帳から自動生成（`V6_1_M1_CONTRACT_TICK.md`）。

## M2 魔法の除去・先史・生態系
- WCDE の実行経路から魔法・ファンタジー種族を除去: 設定（config schema 2）から magic / species を廃止、`options.magic=false`、世界生成フォームの「魔法」を削除。v5 の世界だけ従来どおり（`civ-sim` は `options.wcde` のときだけ stepMagic を登録しない）。
- 解像度: 既定 3,000 セル（標準）／6,000（追加）／上限 20,000。`RESOLUTION` に定数。
- 先史（約 50 万年）: 古代型人類（`archaic`）の集団から始まり、全体の 30〜55% の時点で現生人類が現れ、隣接する集団へ置き換わる・混血していく。技術は月次と同じ発生率の関数（`emergenceRate`）を経過年数で積分する。最後の 15% は文化の累積で発明が急に速まる（建国の候補が必ず現れるように）。8 シードすべてで候補 4〜48。
- 生態系（`wcde/domains/ecosystem.js`）: セルごとに flora / fauna / deg（0〜1）。気候（氷期）・狩猟・耕作・放牧と相互作用し、`ecoMult()` が収容力に掛かる（0.55〜1.15）。先史は粗い刻み、月次は年 1 回。診断に `ecoSummary`・整合性に `checkEco`。
- 建国: 政体の選択肢は、成立する集団の技術（`polity:*` の解禁）から導く。建国画面に「先史の観察（読み取り専用）」（系統の移行・技術の出現・人口と氷期の推移・生態系）と、候補の文化・言語・宗教・場所・選べる政体を表示。

## M3 統合技術ツリー
- `civ/techtree.js`: 11 分野 × 14 列、**129 ノード**。前提は AND で、列は「max(宣言した時代, 前提の列+1)」で構造的に左→右へ進む。各ノードに E（理想条件の期待年数）・成立条件（規模・定住・地理/資源）・解禁（caps）・効果（fx）・背景。`validateTree()` で循環・前提欠落・効果のないノードを検査。文書 `V6_1_M3_TECH_TREE.md` を自動生成。
- `civ/tech.js` を書き直し: 研究点・研究キューは無い。**独立発生**（発生率 = 1/E × 人口・既存知識・交流・都市化・経済・学習・競争・世界の知識の蓄積）、**伝播**（接触・交易・教育制度・併合・移住の経路別に件数を数える）、**喪失・再発見**（人口が必要規模の半分を割ると。前提を欠くと機能が劣化する `techFunction`）、**制度化**（国が採用）、**普及**（国内人口に占める保有の割合。派生）。乱数は (historySeed, 期間, 集団, 技術) のハッシュで、他の機能の乱数消費に左右されない。
- 解禁（caps）から導く: 行動（都市建設・要塞・制裁・秘密工作・核）・条約種別・政体・部隊の種類。行動の候補生成も実行も同じ表（`ACTION_CAP`）を通る。経済は fx（産業・収容・交易）から。
- 創造主の編集（`wcde/techedit.js`、権限 creator のみ）: ツリーの前提・効果・解禁の重ね書き、集団・国家への付与／剥奪。**変更前に影響（依存する技術・保有する集団・採用する国家）を返し、確認なしには実行しない**。創造主の台帳に記録。
- UI: 技術タブを左→右のグリッドに作り直し（直交する線・レーン帯・5 状態を色＋記号＋枠線で区別・検索・分野絞り込み・拡大表示・詳細に成立条件/解禁/効果/世界での広がり）。

## M4 歴史資料（アーカイブ）
- AI の判断（観測・候補・採点・理由）は**保存しない**。`civ.decisions` は無くなり、`record()` は一時のオブジェクトを返すだけ。連続値の小さな調整（税率・動員・救済など）は出来事にしない（`RECORDED`）。
- 出来事は `civ.events`（直近 36 か月の作業バッファ）に積まれ、**安全な境界**（`advanceMonths` が成功したあと＝`safeAdvance` の各チャンクの後）で `commitArchive` が世紀ごとのチャンクへ移す。細かい種別（接触・コホート・生業の変化など）は件数だけ数える。取り消し点を跨がない。
- 因果リンクは `direct` のみ保存（`strong`/`plausible` などは落とす）。出来事に `facts`（国家の成立・政体・領域・戦争・条約）と媒体（口承/刻まれた記録/紙/印刷、先史は遺跡）を持たせた。
- **残存**: 決定的（`hash(historySeed, recordId)` と残存確率の比較）。残存確率は経過年に対して単調に下がるだけなので、一度失われた資料は復活せず、コンパクションで安全に捨てられる。直近 20 年は必ず残る。古いチャンクは JSON 文字列（cold）で持ち遅延読み込み。
- **過去の再構成**: 全月の履歴（`history.js` の時系列）は WCDE の世界では記録しない。`pastView()` が残っている資料から国家・領域・戦争を再構成し、資料の無い部分は不明として返す。地図・国家一覧・年表・Obsidian 出力・保存（civ-chunks）をこれに接続。年表に世紀ごとの残存率を表示。
- 検査: 同じシード・同じ操作で archive / states / techWorld / eco が一致、残存の単調性（違反 0）、JSON を経由しても同じ資料が残る。

## 既知の限界・M5 以降へ持ち越し
- 技術の進みは遅めで、129 件の完走には数千年かかる（E は先史・歴史で別に調整。**M9 の長期計測で E と POOL を再調整**）。国家のドクトリンの制度化（M6）・戦争（M6）はこれから。
- 同盟・条約の期限切れが同じ月に大量に起きる（「不可侵条約が期限を迎えた」が並ぶ）。M6 の外交再設計で扱う。
- 1,390 集団の世界では 1 年 0.48 秒。UI の再生速度（5 年/秒）には届かない。
- v5 の画面（index.html）は判断記録を表示できない（v6.1.0 の世界には存在しない）。削除はしていない。
- 古い時代の資料が無い国家は「名前の資料が失われた国家」と表示する。
