# 大規模歴史のためのUI設計（国家1,000以上・歴史10,000年以上・戦争10,000回以上）

状態: **設計（2026-10-22）。V5-M10（UIの主要画面再構築）の入力仕様。** 実装済みなのは、M1 の「人口集団」ウィンドウ（ページ送り・絞り込み・並び替えの方式）だけ。
基準: `02` 指示書 §12、`05` 運用指示（UIは暗い色に変えるだけではない／地図の視認性・情報分類・状態変化との連動・入力の明確さをテストする）。主な対象機は Surface Go 4（1280×853）。

## 1. 想定規模と、そこから出る原則

| 量 | 想定 | 意味 |
|---|---|---|
| 同時に存在する国家 | 1,000 以上（歴史を通した累計は数千〜） | 一覧・地図ラベル・外交表が全件表示できない |
| 歴史 | 10,000 年以上 = 120,000 か月 | 年表・グラフ・保存が「全件を描く」前提で作れない |
| 戦争 | 10,000 回以上（戦闘は数十万） | 「進行中の戦争」を並べるだけの画面が成り立たない |
| イベント・AI判断 | 数百万件 | 毎回の全走査・全件のDOM化が不可能 |

原則（M10 のレビュー基準にする）:
1. **全件を描かない。** 画面に出す件数は常に上限が固定（既定 40〜60 行、地図ラベルは重要度の上位のみ）。残りは検索・絞り込み・ページ・拡大で到達できる。
2. **データは消さない。** 集約・要約・間引きは「表示」だけの話。正本（`.ahmap`、全月の国家状態、判断記録）は削除しない（`05` §2）。
3. **文脈から入る。** 「全国家の一覧」ではなく、プレイヤー国・隣国・関与中の戦争・固定した対象（ウォッチリスト）から始める。
4. **集計は先に作る。** 画面の応答のために、国別・世紀別・種類別の集計とインデックスをデータ層に持つ（M6 の双方向索引、M7 のチャンク）。
5. **速度に応じて粒度を変える。** 高速進行中は通知を要約表示にし、停止すると個別表示に戻る（要約は表示層。記録は個別に残る）。
6. **応答予算。** 操作への最初の反応 100 ms 以内、一覧・窓の表示 200 ms 以内、地図の再描画 5 秒以内（要件）・パン/ズーム中は 16 ms/フレームを目標。M12 で合成データ（国家 1,200・戦争 12,000・120,000 か月）を使って計測し、記録する。

## 2. 画面構成（1280×853 を基準）

```
┌────────────────────────────────────────────────────────────────────────────┐
│ 世界名  ‹ 紀元 1234年7月 ›  ▶ ⏸ 速度  通知●  保存状態            ［検索 ⌘K］ │ 上部
├──┬─────────────────────────────────────────────────────────┬───────────────┤
│左│                                                         │ 右: 文脈パネル  │
│ハ│                    世 界 地 図                          │ 選択中の国家/   │
│ブ│     （国家は重要度LODでラベル。選択は縁取りで強調）        │ 戦争/都市/事件   │
│ │                                                         │ ─ 概要 ─ 操作 ─ │
│ │                                                         │ ─ 関連リンク ─  │
├──┴─────────────────────────────────────────────────────────┴───────────────┤
│ 下部: 多段スケール年表（時代帯／イベント密度）  ＋ 戦争帯 ＋ ニュース要約       │
└────────────────────────────────────────────────────────────────────────────┘
```
- **検索（Ctrl/⌘+K）が主要な入口。** 国家名・人物・戦争・事件・都市・日付（「1234年」）を横断。結果は種類別に上位だけ、Enter で地図と右パネルが連動。1,000 国から探すには、一覧を眺めるより検索が速い。
- 左ハブは分類ナビ（世界／国家／外交／戦争／内政・経済／技術／文化・宗教／歴史研究／設定）。ここから開くのは**大画面の「ブラウザ」**（下記）か、右パネルの文脈。似た入口を散在させない。

## 3. 国家（1,000以上）

- **国家ブラウザ**（ファセット付きの表。窓の主役画面）
  - 列: 色・名前・状態（存続/滅亡/属国…）・人口・面積・技術段階・文化・宗教・安定度・戦争数。各行に直近 200 年の人口の**スパークライン**。
  - 絞り込み: **「この日付に存在した」**（既定は現在）・大陸/地域・規模の帯・文化/宗教・戦争中・属国関係・「ウォッチリストのみ」。並び替えは列ごと。
  - 実装: 行は仮想スクロール（見える行だけDOMを作る）。件数と絞り込みはインデックスで即時。
- **地図上の国家表示（LOD）**
  - ラベルは重要度（人口×面積×威信）の順位で上位 N のみ。ズームで N が増える。衝突回避はラベルごとの矩形で貪欲に配置。
  - 色: 1,000 国は色が足りない。**隣接する国家は必ず区別できる配色**（グラフ彩色）＋大国は固有色、小国は系統色（文化・宗教の色相）＋縁の線種で補う。色だけに頼らない（`02` §12.3）。
- **系譜**（分裂・合併・継承）は既定では折りたたみ。選択した国の**エゴネットワーク（前身・後継 2 階層）**から広げる。全体グラフは描かない。
- **ウォッチリスト**: プレイヤー国・隣国は自動、ほかは★で固定。ニュース・戦争帯・年表はウォッチリストを優先表示。

## 4. 歴史（10,000年以上）

- **多段スケール年表**（下部）: 時代帯（千年）→ 世紀 → 十年 → 年 → 月 とズーム。各段の背景に**イベント密度のヒートストリップ**（種類別に色分け）。ドラッグで範囲選択すると、その範囲の事件ブラウザが開く。
- **日付ジャンプ**（入力・検索・ブックマーク）。時代名は世界カレンダー設定に従う。負の年・遠未来に対応。
- **過去参照**: 任意の月へ移ると「閲覧中（過去）」の帯を出し、地図・一覧は M7 の復元状態を使う（読み取り専用）。現在へ戻るボタンを常に出す。過去の分岐作成はしない（`02` §0.1）。
- **自動の時代区分**: 国家数・人口・技術の変化点から「時代」を自動で切り、年表と地図年代表の見出しにする（表示用。正本ではない）。
- **進行速度**: 速度に応じて通知を「個別／月次の要約／10年の要約」に切り替える。要約は件数と代表事件。個別は常に事件ブラウザから辿れる。

## 5. 戦争（10,000回以上）

- **進行中の戦争**は右下に「関連度の高い上位」だけ（プレイヤー関与・隣国・規模の上位）。残りは件数のバッジ→戦争ブラウザ。
- **戦争ブラウザ**（表）: 名前・期間・参戦陣営（国数）・規模（総兵力/死者）・結果・原因・戦場の地域。絞り込み: 期間・参戦国・結果・規模の帯・進行中のみ。
- **戦争の家族（シリーズ化）**: 同じ当事者間の繰り返しの戦争は「第N次○○戦争」としてまとめ、一覧では 1 行（展開で個別）。10,000 回の戦争が数百〜千の「家族」になって読める。命名は既存の戦争名規則（直近100年で同じ国どうしなら「第N次」）に合わせる。
- **紛争の熱図**: 地域 × 世紀のヒートマップ（戦争開始数・死者）。セルを押すとその条件で戦争ブラウザが開く。
- **戦争ウィンドウ**（個別）は現行の構成を維持しつつ、戦闘ログは仮想スクロール。1 つの戦争が長期でも開ける。
- 戦闘（数十万件）は戦争の下にだけ置く。単独の「全戦闘一覧」は作らず、検索経由。

## 6. 事件・判断記録・因果グラフ（数百万件）

- **事件ブラウザ**: 種類・関与者・場所・日付範囲で絞り込み。カーソル式ページ送り（件数が多くても先頭から読まない）。
- **判断記録**（国家AIの決定）は、国家ごと・月ごとの索引から開く。候補評価の内訳は行を開いたときに読み込む。
- **因果グラフ**は常に**ある事件を中心にした局所**（原因側・結果側とも深さ 2 まで、ノード上限 60）。さらに広げるのは明示操作。上限を超えたら理由を表示する（黙って切り捨てない）。
- 画面用の要約・並べ替えは行っても、正本の判断記録・状態は消さない。

## 7. 入力・フィードバック・アクセシビリティ

- 実行系の操作は「確認 → 成功/失敗の理由 → Undo 可能か」を一貫して表示。失敗は理由つきで残す。
- 色だけに頼らず、線種・形・ラベルの縁取り・凡例を併用。ローカルのフォールバックフォント。機能アイコンはベクターで統一。
- キーボード: 検索 `⌘/Ctrl+K`、日付ジャンプ、ブラウザの上下移動、Esc で閉じる。

## 8. 検証（M10・M12 に組み込む）

1. 合成データ生成器: 国家 1,200／戦争 12,000／120,000 か月／イベント 300 万を作り、各ブラウザの初回表示・絞り込み・ページ送りの時間を測る（目標は §1-6）。
2. UI テスト: 一覧がどの件数でも DOM 行数が上限内／ラベル衝突の件数／隣接国の色の区別（最小色差）／過去参照時に操作が無効になること。
3. 計測の記録: 端末・件数・設定を `docs/` に残す。未達を黙って受け入れない。Surface Go 4 の実測は未取得（開発環境の値を実機の値として扱わない）。
