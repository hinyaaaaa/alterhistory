# UX改善ロードマップ（2026-10）

## 済み
- 標準の alert/confirm をアプリ内ダイアログに統一（削除・統合・撤退・核の実行）
- Esc で窓を閉じるとき、閉じる時の後処理が走るように修正
- 狭い画面・タッチ向けの窓/表/ボタンの調整
- 戦況に「降伏までの民意の残り」を表示
- 実マップが無くてもテストできる合成マップ（`npm run samples` → `SAMPLES_DIR=tests/.samples npm test`）

- 戦争ウィンドウを4タブ（概要・部隊・経過・講和）にし、講和タブに戦争スコアの内訳を表示
- ⚖ バランス調整ウィンドウ（`js/core/sim/balance.js`。維持費・番狂わせ・スコア・割譲費用など7項目。ブラウザに保存）

- 実ブラウザ（Chromium）での自動確認 `npm run test:e2e`（`tests/e2e/`）。起動・全ウィンドウ・戦争・編集とUndo・保存と開き直し・書き出し・狭い画面とタッチを検査し、画面は `/tmp/e2e-shots/` に保存する
- E2Eで見つけて直した不具合: Undo/Redoで地図が再描画されない／確認ダイアログのEscで背後の窓も閉じる／講和タブの優勢度が0%／狭い画面でレイヤー等のメニューが画面外にはみ出す
