# ロードマップ

## 現在の方針
新機能を足す前に、基盤・説明可能性・操作の一貫性を整える。

## 済み
- 標準の alert/confirm をアプリ内ダイアログに統一（削除・統合・撤退・核の実行）
- 戦争ウィンドウを4タブ（概要・部隊・経過・講和）にし、講和タブに戦争スコアの内訳を表示
- 戦争の勝敗は、召集の変更・撤退・損耗・ハプニング・核の使用のたびに、いまの戦力・士気・民意で判定し直す
- ⚖ バランス調整の値を**地図に保存**（`map.ext.data.balance`）。同じ地図は、どの端末でも同じ設定で動く
- `npm test` を合成マップだけで完結させ、常に緑にした。実マップ専用の検証は `npm run test:compat` に分離
- GitHub Actions（`npm ci` → `npm test` → `npm run build` → dist とソースの一致確認）、`package-lock.json`
- 死んだコード（`military-dialog.js`・サイドバー開閉・パネルドック）を削除。「distから復元」の注記を削除
- 実ブラウザ（Chromium）での自動確認 `npm run test:e2e`

## v2.0.0 済み（静かな戦略卓）
- UI の全面刷新（ハブ・時計・新聞・戦争状況・ホバー）、窓の整理、条約と外交、疫病・災害のゾーン（一時表示）、旅の廃止、保存形式の版 2（`docs/CHANGELOG.md`）

## 公開前のブロッカー
- 旧UIに由来する説明（ヘルプ・テスト名・コメント）に「攻撃対象の選択」などが残っていないか確認する
- 戦争ウィンドウと講和ウィンドウの間の行き来を減らす

## 短期
1. 戦争の結果の「なぜ」を出す（勝敗の主因・決定打・講和への影響）。戦争スコアの内訳はあるが、主因の表示がまだ無い
2. 設定メニューの分類（世界／国家間／シミュレーション／高度）
3. Chronicle の書き出しを「JSON／Markdown／両方」の選択式にする
4. 徴兵の係数や兵科ごとの維持費の重みも、バランス調整に出す

## 中期
- パネルの差分更新（年表・戦争履歴など大きい一覧から）
- 主役ウィンドウの明確化（複数の窓が重なったときの扱い）

## 大型機能（基盤が整ってから）
地図の自動生成、頂点編集、Worker化、3D

## 完了条件（公開版）
- `npm test` と CI が緑
- ドキュメントが現行コードと一致している
- 勝敗と戦争スコアが、画面の数値から説明できる
