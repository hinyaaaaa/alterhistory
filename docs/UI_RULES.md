# UI_RULES — v7 の画面の規則

これから画面を足す人（と AI）が、モック（`AlterHistory_v7_UI.html`）から外れずに実装するための規則。画面を足す前に、この文書の §0〜§7 を読み、§8 のチェック表で自己点検する。
モックとの食い違いが出たら、**モックが正**。モックにない部分は、この文書の規則から導く（新しい見た目を発明しない）。

## 0. 原則（破らない）
1. **機能を減らさない。** 旧画面にあった操作は、新しい画面のどこかから必ず届く。消すときは `docs/UI_FEATURES.md` に理由と行き先を書く。
2. **見た目の値を直書きしない。** 色・書体・寸法・動きは `css/v7-tokens.css` の変数だけを使う。
3. **世界は `dispatch` でしか変えない。** 画面から `w.civ` を書かない。操作は `store.js` の `act`（担当国）・`creator`（創造主）・`run`（管理）。操作が足りなければ `js/core/wcde/commands.js` に `defineCommand` を足す。
4. **英語の見出し・操作説明文は出さない。** 見出しは日本語 1 つ。説明は、操作の結果が分からないときだけ、1 行で。
5. **数字は嘘をつかない。** 値が無いときは「—」。`null`・`undefined`・`[object Object]` が画面に出たら不具合。

## 1. 画面の構成（変えない）
| 場所 | 中身 |
|---|---|
| 上部バー（高さ 60px） | ロゴ／国旗・国名・政体・為政者／指標 5 つ（人口・国庫・安定度・軍事力・正統性。創造主は世界の人口・国数・進行中の戦争・平均安定度）／日付と速度（停止＋1〜4）／担当国⇔創造主の切替／歯車 |
| レール（幅 64px） | 入口 6 つ。担当国: 状況・内政・軍と戦争・外交・世界・年表。創造主: 世界・国々・軍と戦争・外交・年表・介入。**創造主に「内政」は置かない** |
| 左パネル（幅 380px） | 選んだ入口の中身。`[` `]` で畳める。畳んでも地図は欠けない |
| 地図 | 残り全部。右上に「表示」（18 層）と「検索」。国をクリックすると右上に国のカード |
| 通知 | 右下に最大 3 枚。重大は縁が赤く光り、確認するまで残る。通常は約 6 秒 |
| 全面画面 | 上部バーの下を覆う。後ろに地図を透かす。右上の「閉じる」か Esc で戻る。**開いている間は時間が進まない**（入力の途中で世界が変わらないように） |

右側にパネル・タブ・ニュース欄を作らない。入口を 7 つ以上にしない。

## 2. 見た目の約束
- **色の役割**: 真鍮 `--br`＝選択と主操作／青 `--bl`＝自国・味方／紫 `--pu`＝外交・従属／赤 `--dn`＝危険・敵対・戦争／緑 `--ok`＝良化・友好／黄 `--wa`＝注意。意味を変えない。
- **書体**: 見出し・本文の強調は `--mi`（Zen Old Mincho）、本文は `--go`（Zen Kaku Gothic New）、**数字は `--nm`（Barlow Condensed、等幅の数字）**。明朝の装飾体は使わない。
- **角**: ボタン・札は角を 2 か所だけ切る（`--cut`）。丸角にしない。
- **文字サイズ（基準 1280×853）**: 見出し 21px／小見出し 11.5px／本文 13px／補足 11〜12px。11px 未満にしない。
- **動き**: 通常の動きは 0.15〜0.3 秒。常時動くものは作らない。`--t-*` を使う。
- **層**: `--z-bar` < `--z-card` < `--z-full` < `--z-modal` < `--z-toast`。数字を直書きしない。
- **フォント**: Google Fonts の読み込み（`index.html`）。オフラインでは同系統の日本語フォントに落ちる（見た目が少し変わる）。

## 3. 部品（`js/ui/v7/ui.js`、`css/v7-components.css`）
CSS クラスは `v-` で始める。画面側は部品の関数を呼ぶだけで、クラス名を直書きしない。
| 部品 | 関数 | 使いどころ |
|---|---|---|
| ボタン | `Btn(label, onclick, kind, opt)` | kind: 空=主（1 画面に 1 つ）／`g`=弱／`d`=危険（宣戦・解体など取り返しがつかないもの） |
| 行 | `Row({color,title,sub,tag,small,onclick})` | 一覧の 1 件。左の縁の色が意味を持つ |
| カード | `Card(...)` | 数値や状態のまとまり。四隅に真鍮の印 |
| 滑り棒 | `Slider({label,min,max,step,value,fmt,onchange})` | 割合・段階。**離したときだけ命令を出す** |
| 表 | `Table(cols,rows,{sort,dir,onsort,onrow})` | 国々・比較。見出しを押して並べ替え |
| 見出し | `H2(番号,題)` `H3(題,補足)` | 入口の題と節。番号は入口の順（01〜06） |
| 小部品 | `Chips` `Tabs` `Tag` `Spark` `Gauge` `Ring` `Delta` | 絞り込み／切替／札／推移／目盛り／輪／増減 |
新しい部品が要るときは、まず既存の組み合わせで作れないか考える。足すなら `ui.js` と `v7-components.css` の両方に、同じ名前で足す。

## 4. 操作の 3 段階（どれで作るか）
1. **値を変えるだけ** → 左パネルの滑り棒・チップ。その場で `act`。確認を挟まない（代償が大きいものを除く）。
2. **1 回の決定** → 確認カード（`openDialog`、中央、後ろを暗くする）。`重大` は決断（`decision.js`）。
3. **集中して作る** → 全面画面。宣戦・講和・動員・軍団の編成・技術ツリー・ドクトリン・国の情報の編集・反乱・世界の設定。

**全面画面の作り方（契約）**
- 開いている画面は `S.screen = { key, id, ... }` が持つ。`openXxx()` は `S.screen` を設定して `S.hooks.panel()` を呼ぶだけ。
- 画面の定義は `js/ui/v7/screens.js` の `screenSpec()`（戦争系は `war-screens.js`）が返す: `{ key, title, build(), footer?(), bare?, side?, onClose }`。`build` は **呼ぶたびに DOM を作り直してよい**（左パネルを描くたびに作り直される。スクロール位置は保たれる）。
- 一時的な入力（選んだ部隊・目的など）は `S` に持つ。画面の DOM に状態を持たせない。
- 決定ボタンは `footer`（下の固定欄）に置く。画面の途中に置かない。
- 閉じるときは `onClose` で自分の `S.*` を片づける。
- 旧部品が `S.full = {...}` を直接作る場合（戦争の詳細 `war`・軍団の詳細 `corps`・軍団の編成 `corpsnew`・国の編集 `nedit`・反乱 `upr`。画面の中から開くものは `main.js` の `CHILD_FULL`）は、**画面を開いている状態を `S` の別の項目に持たせる**こと。`S.full` はパネルを描くたびに消される。

## 5. 入口を足す・画面を足す手順
**入口（レールの項目）**: 6 つを超えない。どうしても足すなら、既存の入口の中の節か全面画面にできないか先に検討し、無理なら `docs/DECISIONS.md` に理由を書いてからにする。
1. `js/ui/v7/panels-p.js`（担当国）または `panels-c.js`（創造主）に `pXxx()` を書く。先頭は `H2("0n", "題")`。
2. `js/ui/v7/panels.js` の `PANEL` に登録し、`chrome.js` の `ENTRIES` に `[key, 名前, アイコン]` を足す。
3. アイコンは `icons.js` に線画（24×24、`stroke` 1.4）で足す。
**全面画面**: `screens.js`（または専用ファイル）に `xxxSpec(sc)` を書き、`screenSpec()` の分岐に足し、`openXxx()` を export する。
**命令**: §0-3。`docs/COMMANDS.md` は `npm run docs` で更新。
**新しい言葉**: 通知の名前は `store.js` の `LABEL` に足す。

## 6. 旧部品（v6）の扱い
`js/ui/v6/` の部品（国家ページ・外交の表・軍団の詳細・建国フローなど）は、機能を保ったまま `v-legacy` の中に載せ、`css/v7-legacy.css` で見た目を揃えている。
- 旧部品を**新しい見た目に置き換える**のは歓迎。置き換えたら旧部品を削除する（未使用コードを残さない）。
- 旧部品に機能を足さない。足すなら置き換えてから。
- `v7-legacy.css` に新しい規則を足さない（旧部品を揃えるためだけの置き場）。

## 7. テスト
- 画面を足したら、`tests/e2e/v7.e2e.mjs` に「開く→中身がある→閉じる」を足す。コンソールエラー・未処理例外が 0 であること。
- 撮影して目で見る（1280×853）。モックと並べて、配置・色・文字の大きさが合っているか確認する。
- 入口を押す操作を試すとき、`S.hub`・`S.screen` を直接書かず、ボタンを押す（実際の動線を通す）。
- 閾値を緩めてテストを通さない。
