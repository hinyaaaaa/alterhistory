# v5.3.0 UIの一新（ドック方式・大規模対応）

試作（GitHub `prototype` ブランチの `prototyoe/`）を土台に、v5.2.0 へ統合した。画面の骨格は `js/ui/v53/`、見た目は `css/v53.css`。
本体との接続は `js/ui/v53/boot-live.js` の `bootV53()` 1 か所（`js/main.js` から呼ぶ）。

## 目標: どんなに年・国・戦争が積もっても止まらない
原則は `docs/UI_SCALE_DESIGN.md`。**画面に出すものを絞る（見える行だけ・上位だけ・区間に束ねる）が、履歴は削除・要約しない。**

| 部品 | 方法 | 計測（300 万件・1 万年／水増し世界。開発環境） |
|---|---|---|
| 出来事の一覧 | `scale-index.js`: `civ.events` の追記分だけを取り込む増分索引。分類別・月・期間・関与者（本体の `graphIndex`）を二分探索で引く | ページ取得 約 0.4ms 以下 |
| 検索（タイトルの部分一致） | 8ms ごとに区切って走査し、続きは次の呼び出しで進む（`pending`）。結果は保持して、増えた分だけ追う | 完了まで約 1 秒・1 回の呼び出し p50 6ms／p95 約 50ms（GC 込み） |
| 戦争・条約・文化の一覧 | 並べ替え・絞り込み済みの結果を保持（出来事が増える／月が変わるまで再計算しない） | 月の直後の初回 約 24ms（3 万件）、以後 0.2ms 以下 |
| 年表の目印 | `bandBuckets`: 区間の境界ごとに二分探索で件数・危険の有無（累積件数）を引き、最大 160 区間へ束ねる（範囲・件数に依らない）。描き直しは 0.4 秒に 1 回まで | 全期間 0.2ms 前後 |
| 時間軸の範囲 | 全期間／直近 1000・100・10 年の切り替え | — |
| 仮想スクロール | 行高 × 件数が 600 万 px を超えたら、スクロール位置の割合を行番号へ比例で対応づける（ブラウザの要素の高さ上限対策） | 2 億行でも先頭〜末尾に届く |
| 国家数の数え直し | 出来事か月が変わったときだけ | — |

試作からの変更点: 出来事一覧の毎月の全件走査をやめた／年表の目印が先頭 4,000 件までだったのを区間集計にした／戦争一覧の既定を「継続中」にした／戦争・出来事を「国家で絞る」「直近 N 年で絞る」ようにした／詳細に「一覧で見る」入口（件数の多い関連は一覧へ）を足した。

## 本体との接続（main.js）
- 従来の外枠（ハブ・時計・ニュース・戦争状況）は `body.v53-on` で画面外へ（部品は残す）。`#stage`（地図）を v5.3 の中央スロットへ移し、従来の編集パネル（`#sidebar`・`#edit-panel`）とウィンドウは地図の上に重ねる。
- Space は v5.3 のアダプター経由（重大イベントの確認待ちの間は時間を再開させない）。ほかのショートカットは従来のまま。v5.3 側のキー処理は `keyboard: false` で止めている。
- 従来のウィンドウ（国家・外交・戦争・経済・文化・宗教・年表・詳細設定）は「世界」領域の「従来の画面」から開ける。**これらは手動で作った国家用で、文明シミュレーションの国家は載らない**（国家の詳細は右ドック）。

## 採用しなかったもの（要判断）
- Ctrl+K の横断検索の画面: アダプターの `search` は実装・テスト済みだが、画面は作っていない（試作の移行表「採用しない」に従った）。
- 戦争の家族化: 個々の戦争のまま（試作の方針に従った）。

## テスト
`v53-scale-index`（正しさ＋ 300 万件の応答時間）／`v53-live-scale`（実アダプターを 100 万件・3 万戦争・4,000 国家に水増し）／`v53-virtual-list-scale`（2 億行）／`tests/e2e/v53-live.e2e.mjs`（本体に組み込んだ画面を Chromium で）。時間の閾値は開発環境のもので、Surface Go 4 の実測ではない。
