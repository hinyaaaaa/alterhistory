# v6.21.0 事件の物語

v6.20.1 のあと、実際に遊んで出た指摘（出来事が同じものの繰り返し・暗殺のあとに人を選べない・役職の名前と効果・国策の題名）に応えた版。

## 設計
- `js/core/wcde/event-variety.js`（新）: 出来事 1 回ぶんの舞台 `varOf(ctx, st, ev)` = `{ place, person, person2, incident, scene }`。決定的（世界の種・国・出来事・月から決まる）。場所は `warfare.placeName`（集落の名前）、人物は `ctx.nameGen.person`（その土地の言語）。担当国の決断には `payload.v` に入れ、選んだあとの年表でも同じ名前を使う。
- `events.js`: `fill` に `{place} {person} {person2}`。決断の見出しは事件名、本文は `〈元の見出し〉＋元の本文＋場面の一文`。年表は `国名で「事件名」（選んだ結果）`。間隔を 120 → 240 か月。
- `events-data.js`: 56 個を削除（`-C`＝連鎖の行き先でも元でもないものだけ）。`dictator_assassination` / `king_sudden_death` の `x` を「何もしない」まで含めて指導者交代にした。
- `decisions.js`: `succession(ctx, st, cause)`。cause = die / assn / abd / coup。assn・coup は側近の候補（`plot_general` `plot_vizier` `plot_noble`）が加わる。coup を選ぶと安定度 −5%・衝撃。`events.js` の `leaderChange` は、担当国なら coup でもこの決断を出す。
- `offices-data.js` / `regimes.js`: 「名前:印」。`TAGS`（役職 id → { b, d }）。`officeInfo` は印から効果を決める（乱数なし）。ruler は効果なし。
- `policies.js` / `ui/v6/badges.js` / `ui/v6/policy.js` / `index.html`: 国策 26 個・図柄・題名。

## 注意
- 役職 id は「政体_番号」（並び順の番号）で、名前の並びを書き換えたので、v6.20.1 以前の保存では、新しい形式の役職 id が**別の役職（別の名前）に変わる**。旧い官名（宰相・元帥などの旧来の id）はそのまま。
- 担当国の AI 以外の国は、これまで通り利害で選択肢が自動で選ばれる（後継は自動）。
