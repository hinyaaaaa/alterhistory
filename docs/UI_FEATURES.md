# UI_FEATURES — 旧画面（v6.21）の操作の行き先表と、モックとの差

「機能を減らさない」ことの台帳。**旧画面にあった操作は、すべて下のどこかから届く。** 状態: ◎=モックどおりの新しい画面／○=機能は同じで、見た目は新しい枠・部品に揃えた旧部品／△=一部のみ／×=まだ（理由つき）。

## 2. モックにあって、まだ実装していないもの（正直な一覧）
| 項目 | 理由・次の手 |
|---|---|
| 国家の統合（創造主「国々」） | エンジンに命令が無い。`commands.js` に `creator.mergeStates` を足してから画面を作る |
| 地図の編集（地形の造成・標高・気候帯） | 地図の書き換え命令が無い（地形生成側の担当） |
| 関係の表の行にカーソル → 地図に線 | 地図側の強調 API（`hl`）の拡張が要る |
| 国のカードの「首都」表示 | 首都の都市名の引き方を決めてから |
| 戦争の詳細の作り直し（モックの戦争画面の 2 列・戦線の矢印） | 旧部品のまま。矢印の命令 `war.setPlan` は未接続 |
| 戦争目的の「対象の国」を選ぶ（解放・賠償を第三国に） | 宣戦画面は「相手国が対象」のみ |
| 講和会議の細かな要求（割譲の土地・解放の対象） | 要求の種類のうち、対象が要らないものだけ |
| 国旗エディタ・反乱・軍団編成・建国フローの見た目の作り直し | 機能は旧部品のまま。置き換えは §6（UI_RULES） |
| 系統図（文化・言語・宗教）の入れ子表示 | 旧部品のまま |
| 起動画面の背景の増量・ロゴの差し替え | 現状の風景 10 種・羅針盤を維持 |
| 初回の案内・BGM・推移の矢印 | v7.1 以降（決定済み） |
