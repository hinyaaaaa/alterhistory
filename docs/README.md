# ALTERHISTORY — 架空世界地図

[Azgaar's Fantasy Map Generator](https://github.com/Azgaar/Fantasy-Map-Generator) で作った地図を、
日本語のまま軽く見て、保存できるアプリです（Surface Go 4 のマウス・キーボード操作向け）。

> **現在の状態: 「読み込み・表示・編集・書き出し」に加えて、時間進行・人口/産業・軍事・戦争・外交のシミュレーションまで。地図の自動生成（地形・都市などをゼロから作る機能）はまだありません。**
> できること・できないことの一覧は `docs/ARCHITECTURE.md` を見てください。

## 使い方

1. `index.html` をダブルクリックして、Edge か Chrome で開く（インストールもサーバーも不要）
2. Azgaar 形式の `.map`（`.map.gz` も可）を、画面にドラッグ＆ドロップする
3. ホイールでズーム、ドラッグで移動。`?` キーで操作一覧

| 操作 | |
|---|---|
| `O` | ファイルを開く |
| `Ctrl+S` | 保存（ALTERHISTORY 形式） |
| `1`〜`5` | 色分け: なし / 国家 / 文化 / 宗教 / 属州 |
| `B` | 下地: バイオーム ⇔ 標高 |
| `C` `R` `T` `U` `L` | 海岸線 / 河川 / 道路 / 都市 / ラベル の表示切替 |
| `F` `+` `-` `←↑→↓` | 全体表示 / 拡大縮小 / 移動 |

「書き出し」メニューから PNG（2倍の解像度）、SVG、Azgaar 互換 `.map` を作れます。
ALTERHISTORY 形式のファイルは Azgaar 公式でも開けます（固有のデータは無視されます）。

## 編集

上のツールバーで編集ツールを選びます。

| ツール | できること |
|---|---|
| 選択（`V`） | クリックした都市・マーカー・セルの中身を見る。右側のパネルで、名前・文章・追加の属性・外交関係を編集できる |
| 国家/文化/宗教/属州（`1`〜`4`） | ドラッグした範囲を、右上で選んだ対象で塗り替える |
| 地形（`5`） | ドラッグした範囲のバイオームを塗り替える（水域は塗れない） |
| 都市を置く（`6`） | クリックした場所に都市を追加する（人口は近隣都市からの見積もり） |
| マーカーを置く（`7`） | クリックした場所にマーカー（温泉・鉱山など）を追加する |

ブラシの大きさは `[` `]` キーか、ツールバーのスライダーで調整します。
編集は `Ctrl+Z` / `Ctrl+Y` でいつでも元に戻せます。

## 時間・軍事・外交

画面上部の時間バーで、歴史の進行を操作します。

| 操作 | |
|---|---|
| `Space` または ▶ ボタン | 時間の進行を開始・停止（既定 1年=2分。速度は変更可） |
| 「+1ヶ月」ボタン | 停止中でも手動で1ヶ月ずつ進める |
| 年月の表示をクリック | 年月を直接指定する／時代の名前を設定する |
| 上部バーの「設定」 | 国家・文化・宗教・属州・戦争・講和・外交・軍事・隠密・核・通貨・バランス調整などの窓を開く |

時間が進むと、各国の人口・産業力が技術水準に応じて緩やかに増え、人口・産業力の一部が
自動的に徴兵されます（本国部隊に集約。前線への配分は手動）。AIによる自律行動はなく、
戦争・外交の判断は常にユーザーが行います。

**戦争ウィンドウ**（概要・部隊・経過・講和の4タブ）が戦争の中心です。

- **概要**: 攻撃側・防衛側を選んで宣戦布告します。同盟の拘束力に応じて参戦国が広がります。
- **部隊**: 参戦国の全部隊が並び、チェックを入れた部隊がその戦争の戦力になります。
  戦力・士気・民意が変わる（召集の変更・撤退・損耗・ハプニング）たびに、戦況は判定し直されます。
  戦闘は戦争ウィンドウから「記録する」形で行い、部隊の編成は軍事ウィンドウで行います。
- **経過**: 月ごとの損害とできごとの記録。
- **講和**: 戦争スコアの内訳を見て、講和条約（割譲・賠償・併合・従属）を結びます。

戦争の勝敗は、戦争が続いている間は表に出ません（その時点の戦力から計算される見通しで、講和条約を結ぶ段階で確定します）。
**軍事ウィンドウ**は国ごとの部隊数・兵種を表で比べ、部隊の編成・編集・移動を行います。
**外交ウィンドウ**は国どうしの関係の表と同盟の管理に絞っています。

**バランス調整**（設定 → ⚖）の数値は**地図ファイルに保存**されます。同じ地図は、どの端末で開いても同じ設定で動きます
（既定値と違う項目だけが記録されます。Azgaar互換形式で書き出すと含まれません）。

## 開発

```
npm install
npm run build       # js/ → dist/app.js（dist は js/ から作る成果物。直接は編集しない）
npm test            # 全スイート。合成マップだけで完結し、常に緑であること
npm run test:compat # 実Azgaarマップでの互換性検証（SAMPLES_DIR=実マップのフォルダが必要）
npm run test:e2e    # Chromium での実ブラウザ確認
```

`npm test` は実行のたびに合成マップ（`tests/.samples/`）を作り直します。実マップ専用の検証項目
（旧形式の判定・計測線・交易・namesbase、書き出し画像の画素比較など）は `npm run test:compat` にだけ含まれます。
GitHub Actions（`.github/workflows/ci.yml`）が、push と pull request のたびに `npm ci` → `npm test` → `npm run build` と、
`dist` がソースと一致しているかの確認を行います。

構成と設計は `docs/ARCHITECTURE.md`、ファイル形式の仕様と検証状況は `docs/MAP_FORMAT_SPEC.md`。
**次に着手すべきこと・未実装のもの・仮置きの数値は `docs/HANDOFF.md` と `docs/ROADMAP.md` にまとめてある。**

## 歴史をつくる（かんたん作成 ＋ 好きに設定）

右上の「🏛 歴史をつくる」から開く右パネル。**ボタン1つでまず形にして、気になるところだけ手で直す**ための入口です。

| 段階 | 内容 |
|---|---|
| かんたん作成 | 「国を建てる」「宗教を興す」「文化を加える」。1クリックで仮の名前つきで作られ、塗るツールに切り替わる |
| 領土の決め方 | ✋ドラッグで塗る（既定）／🎲おまかせで決める（空き地から小・中・大）。混ぜてもよい |
| 完了 | 国なら首都を自動で置く（仮の名前。チェックで外せる）。色分けは塗っている間だけ対象に合わせ、終わると元に戻る |
| つくった歴史 | 普通は1行（名前・セル数・首都）。▾を開くと技術水準・ドクトリン・首都・名前の系統・塗り足しが出る |
| 仮の名前トレイ | 仮の名前の件数を表示。「すべて確定」で一括確定（Undo 1回で戻る） |
| 名前の雰囲気 | 「指定する（任意）」を開くと、西欧風・和風などを選べる。既定は毎回おまかせ |

実装: `js/ui/history-builder.js`（UI）、`js/app/builder-actions.js`（手順）、`js/core/edit/territory.js`（領土・首都の選び方）。

## 歴史をつくる：経済・交易／旅・ゾーン／政治・文化の深さ

パネル上部の3つのタブで切り替えます（つくる／経済・交易／旅・ゾーン）。

**経済・交易** — 国ごとの国庫・年収・貿易収支を一覧し、開くと売上税・人頭税のスライダー、国庫の直接編集、9種の産物の「産・需・差」、貿易相手が出ます。選んだ国と貿易相手を地図に線で結びます（金=輸出超過、青緑=輸入超過）。年が変わるたびに、人頭税と輸出の売上税が国庫にたまります（Undo 1回で戻る）。産物はバイオーム・人口・海岸・都市人口から毎回計算する簡易モデルで、保存するのは税率と国庫だけ（Azgaar と同じ項目名 `salesTax / pollTax / treasury`）。戦争中の国どうしは取引せず、同盟・友好は有利、不信・敵対は不利、輸出国の売上税が高いと取引は減ります。

**旅** — 区間（出発→到着・移動手段）を足していく。徒歩・行軍・隊商・騎馬（陸）／ガレー船・帆船（水・岸から乗れる）／飛行／滞在。道は速く、険しい地形は遅く計算。距離と日数は縮尺と速さから自動計算。行けない場所は理由を表示。`ext.data.journeys` に保存（Azgaar 本家の旅の行は解釈せず、そのまま書き出しに戻す）。

**ゾーン** — 侵攻・反乱・疫病・災害など13種。「塗って作る」「1点から広げる」。Azgaar 本家と同じ形式（`map.zones`）で保存・書き出し。本家が作った斜線パターンのゾーンも読める（表示は種類の色）。

**政治・文化の深さ（つくる→詳しく）** — 国の政体・政体名・種類、文化・宗教の種類・起源（系統。輪になる指定は拒否）、宗教の神、都市の人口（国の都市人口にも反映）・区分・設備（城塞・城壁・広場・神殿・スラム）。都市タブを新設。すべて Azgaar 本家の項目名で保存。

## 書き出し画像（PNG・SVG）
「書き出し」メニューで、題名・年月（時代名つき）、凡例（今の色分けに連動）、スケールバー（縮尺から1・2・5×10^nの長さを自動選択）を入れる／入れないを選べます。縮尺が無い地図ではスケールバーは出ません（チェックが無効になり、理由を表示）。
