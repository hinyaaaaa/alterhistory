# ALTERHISTORY — 架空世界地図

[Azgaar's Fantasy Map Generator](https://github.com/Azgaar/Fantasy-Map-Generator) で作った地図を、
日本語のまま軽く見て、保存できるアプリです（Surface Go 4 のマウス・キーボード操作向け）。

> **現在の状態: 「読み込み・表示・編集・書き出し」に加えて、時間進行・人口/産業・軍事・戦争・外交のシミュレーションまで。地図の自動生成（地形・都市などをゼロから作る機能）はまだありません。**
> できること・できないことの一覧は `docs/ARCHITECTURE.md` を見てください。

## 使い方

1. `index.html` をダブルクリックして、Edge か Chrome で開く（インストールもサーバーも不要）
2. Azgaar 形式の `.map`（`.map.gz` も可）を、画面にドラッグ＆ドロップする
3. ホイールでズーム、ドラッグで移動。`?` キーで操作一覧

| 操作 | |
|---|---|
| `O` | ファイルを開く |
| `Ctrl+S` | 保存（ALTERHISTORY 形式） |
| `1`〜`5` | 色分け: なし / 国家 / 文化 / 宗教 / 属州 |
| `B` | 下地: バイオーム ⇔ 標高 |
| `C` `R` `T` `U` `L` | 海岸線 / 河川 / 道路 / 都市 / ラベル の表示切替 |
| `F` `+` `-` `←↑→↓` | 全体表示 / 拡大縮小 / 移動 |

「書き出し」メニューから PNG（2倍の解像度）、SVG、Azgaar 互換 `.map` を作れます。
ALTERHISTORY 形式のファイルは Azgaar 公式でも開けます（固有のデータは無視されます）。

## 編集

上のツールバーで編集ツールを選びます。

| ツール | できること |
|---|---|
| 選択（`V`） | クリックした都市・マーカー・セルの中身を見る。右側のパネルで、名前・文章・追加の属性・外交関係を編集できる |
| 国家/文化/宗教/属州（`1`〜`4`） | ドラッグした範囲を、右上で選んだ対象で塗り替える |
| 地形（`5`） | ドラッグした範囲のバイオームを塗り替える（水域は塗れない） |
| 都市を置く（`6`） | クリックした場所に都市を追加する（人口は近隣都市からの見積もり） |
| マーカーを置く（`7`） | クリックした場所にマーカー（温泉・鉱山など）を追加する |

ブラシの大きさは `[` `]` キーか、ツールバーのスライダーで調整します。
編集は `Ctrl+Z` / `Ctrl+Y` でいつでも元に戻せます。

## 時間・軍事・外交

画面下の時間バーで、歴史の進行を操作します。

| 操作 | |
|---|---|
| `Space` または「開始/停止」ボタン | 時間の進行を開始・停止（既定 1年=2分。速度は変更可） |
| 「+1ヶ月」ボタン | 停止中でも手動で1ヶ月ずつ進める |
| `M` または「軍事・外交」ボタン | 部隊・戦争・同盟の管理パネルを開く |

時間が進むと、各国の人口・産業力が技術水準に応じて緩やかに増え、人口・産業力の一部が
自動的に徴兵されます（本国部隊に集約。前線への配分は手動）。AIによる自律行動はなく、
戦争・外交の判断は常にユーザーが行います。

**軍事・外交パネル**は3つのタブに分かれています。

- **部隊タブ**: 国家を選び、「＋新しい部隊を編成」から地図をクリックして部隊を配置します。
  兵科（歩兵・機甲・航空・海軍・特殊部隊・先端技術・核）ごとの数とドクトリンを編集でき、
  「攻撃する」から他国の部隊を選んで即座に戦闘を判定します（結果は双方の損耗として反映され、
  国境はその場では動きません）。
- **戦争タブ**: 攻撃側・防御側を選んで宣戦布告し、戦績を確認します。講和条約では、
  割譲候補（前線の属州や、属州のない前線地域）が自動で提示されるので、割譲する地域と
  賠償金を選んで確定します。
- **同盟タブ**: 2カ国以上（3カ国以上も可能）で同盟を結成し、メンバーを後から編集できます。

## 開発

```
npm install
npm run build       # js/ → dist/app.js
npm test            # 19 スイート・約785項目。実マップで検証する
```

テストは実際の `.map` ファイルを使います。置き場所は `SAMPLES_DIR=フォルダ npm test` で指定します
（`境界線の貴方.map` と `新世界より.map` が必要）。

構成と設計は `docs/ARCHITECTURE.md`、ファイル形式の仕様と検証状況は `docs/MAP_FORMAT_SPEC.md`。
**次に着手すべきこと・未実装のもの・仮置きの数値は `docs/HANDOFF.md` にまとめてある。**
