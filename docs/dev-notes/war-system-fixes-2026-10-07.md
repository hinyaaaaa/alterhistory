# 戦争システム修正（2026-10-07）

## 修正内容
1. **民意が尽きたら降伏する**（`js/core/edit/wars.js` の `exhaustionCollapse`）
   戦争中、ある陣営の国の民意が10以下（`EXHAUST_SUPPORT`）になると、毎月の進行でその陣営が敗北する。経過の記録に「民意の崩壊」が残り、降伏させた側はすぐ戦争スコア全額で講和を要求できる。
2. **長期戦でスコアが上がり続ける**（`currentWarScore`）
   目安の期間を過ぎても戦争が続くと、毎月 +1.6（通常戦）〜+2（総力戦）。上限は限定戦50／非対称戦65／通常戦・総力戦100。
3. **全面降伏（併合）を現実的に**：必要スコア 85→70、費用 100→60。併合は取り分に関係なく戦争スコアをそのまま使える。
4. **割譲の費用を「敗者の領土の割合」に**（`cessionCost`）：領土の全部で70、都市1つにつき+1.5。地図が大きくても数割は要求できる。
5. **勝敗判定の見直し**（`js/core/sim/war-engine.js`）
   - 小さな海軍・空軍は、陸軍の2割5分に満たない規模なら効きにくい（相手ゼロで100%になるのを防止）
   - 重み：陸軍0.6／空0.14／海0.1／士気0.16（士気は差を2倍に広げて反映）
   - ブレ（ノイズ）の最大幅を 0.24→0.18
   - 検証：陸軍1:4・士気30:70の弱い側の勝率 56%→0%。互角なら攻撃側41%。
6. **経過の記録のスクロールが先頭に戻らない**（`js/ui/safe-render.js` の `keepScroll`）。戦争パネル・講和ウィンドウに適用。
