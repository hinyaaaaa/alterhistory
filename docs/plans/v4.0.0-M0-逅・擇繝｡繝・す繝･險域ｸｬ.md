# V4-M0 球面メッシュの計測（途中）

## 測定条件
- 端末: Intel Xeon 2.10GHz（1 コア。クラウド上のサンドボックス）／ Node v22.22.2
- **Surface Go 4 ではない。** 生成 60 秒・再描画 5 秒の判定には使えない。下の値は、メッシュ構築という一部の段階の目安にすぎない。
- コマンド: `node tests/helpers/bench-sphere-mesh.mjs 158`（3 回計測）

## 結果（n=158、249,642 セル、499,280 三角形）
| 項目 | 結果 |
|---|---|
| メッシュ構築（位相まで） | 168〜186 ms |
| 全セルの矩形投影ポリゴン化（継ぎ目・極の処理込み） | 130〜151 ms |
| 全セルの面積計算 | 38〜66 ms |
| 幾何配列の大きさ | 約 22 MB |
| プロセス常駐メモリ | 約 167 MB |
| ハッシュ（決定性） | 351c8523（`sphere-ico-1`） |

## 検査
- 隣接の対称、五角形 12 個、面積の和 = 4π（誤差 1e-5 以内）、極を囲むセルが 2 個、継ぎ目をまたぐセルの境界が連続、を `tests/v400-sphere-mesh.test.mjs` で確認。
