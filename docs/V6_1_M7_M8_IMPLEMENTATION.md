# v6.1.0 M7〜M8 実装メモ（版 6.1.0-m8）

テストは M9 で行う方針のため、この版ではテストの追加・修正をしていない。M9 で更新が要る箇所は末尾にまとめた。

## M7 外交・介入・ニュース

### 外交と新しい戦争モデルの接続（`js/core/wcde/negotiation.js` `warfare.js` `civ/diplomacy.js`）
- 講和の評価は、部隊の戦力比・占領されている／している土地の割合・首都の陥落・封鎖・疲労・国庫・損耗・長期化から決める（旧: 戦争スコアだけ）。
- 講和の条件は 3 種類: **白紙講和**（占領地を返し合う）／**賠償つき**／**占領地の割譲**（占領した土地を占領した国のものにする）。条件を指定しないときは `defaultTerms`（占領で優位なら割譲、そのほかは白紙）。AI も同じ経路。
- 終戦の領土整理は `warfare.settle`: 占領した**国家ごと**に区画が移る（`ops.occBy` を追加）。勝った側は占領地を得る。自陣営の領土は動かない。以前は「受けて立った国の区画 → 開戦国」だけで、受けて立った側の勝利・反撃の占領は反映されなかった。
- **単独講和**: 同盟側の参戦国の講和は、その国だけが戦争から抜ける（`leaveWar`）。主たる交戦国（開戦国・受けて立った国）の講和は戦争全体を終える。
- 条約は `treatyFeasible`（封鎖・制裁・経済の算出・部族の連合の記録手段）で実行可能な範囲に限る。評価と締結直前の再検証の両方で使う。
- **AI の評価の中身（点数・要因・理由）は保存しない**（仕様 §2.5・§9）。提案の台帳に残すのは結果（提案・成立・拒否・別条件・不成立・単独講和）だけ。画面の「相手の評価」は、提案の前にその場で計算して出す。
- 担当国は結んでいる条約を破棄できる（`break_treaty` の候補に担当国の条約を追加）。

### 創造主介入の複数ドメイン化（`domains/effective.js` `intervention.js`）
- 新しい項目: **安定度**（国家）・**人口の収容力（倍率）**（人口。`ctx.stateMult` に掛かる）・**関係値**（外交。相手の国を指定する対の項目。交渉の評価が読む）。経済・軍事・政治の既存項目と合わせて 6 領域。
- 通常計算と分離した残存補正・半減期での収束は従来どおり（補正は `civ.wcde.adjust` に別持ち、通常計算の名目値は書き換えない）。安定度は軍の即応・政治の支持の計算が有効値を読む。

### 創造主の災厄（`catastrophe.js`、命令 `creator.catastrophe`）
- 世界規模／地域規模（国の首都を中心に半径 100〜20000 km）。名称・理由は任意。人口の損失は 1〜95%（集団ごとの損失は指定値を超えない。5 人未満には落とさない）。
- 人口・軍・安定・国庫・文化の緊張・収容力へ即座に反映し、生産・交易・軍事は通常の計算で伝わる。巻き戻さない。乱数は (historySeed, 災厄ID, 集団) のハッシュ（`ctx.rng` を使わない）。
- 現実の災害・攻撃・破壊の手段は扱わない抽象的な創造主介入（何が起きたかではなく、失われた割合と世界の反応だけ）。

### 介入・創造主行動と事実の分離
- 創造主の直接編集は `civ.wcde.edits` だけに残し、`creator_edit` の事実イベントを `civ.events` に作らない。
- 災厄は台帳 `civ.wcde.catastrophes`（行為・理由・指定値）と、事実イベント `catastrophe`（結果。理由の注釈は含めない）に分ける。年表の「創造主の介入」には台帳の側を出す。

### 重大ニュース（`clock.js`）
- 基準を調整可能に（`news.configure`: 重大／主要の閾値・規模の加点・同時に止める件数の上限・種類ごとの基礎点）。設定は保存される。世界設定に「ニュースの基準」。
- 1 回の判定で止める重大ニュースは上限（既定 3 件）まで。超えた分は主要ニュースとして一覧に残る。災厄は損失の割合と世界規模かどうかで点が決まる。

## M8 UI

- **起動画面**: 毎回表示。仮ワードマーク `assets/brand/alterhistory-wordmark.svg`（文字だけ。正式なロゴはファイルを差し替える。AI 生成画像は使っていない）。約 0.9 秒の光の走査、`prefers-reduced-motion` では演出なしで即切り替え。画像が読めなければ文字表示に戻る。
- **通常通知**: v5 の `js/ui/banner.js` を再利用（`ui/v6/notify.js`）。画面上部中央に一時表示、右側に通知欄は作らない。長いエラー（120 字超）は閉じるまで残る。重大ニュース（中央の確認画面）とは別系統。命令の成功・失敗を短く具体的に通知。
- **技術ツリー**: 選択・詳細表示でも表示位置とズームを保持。「選んだ技術へ」「検索結果へ」ボタン。
- **ドクトリンツリー**: 画面上端に根、母線から各系統の見出しへ。左に共通 5 系統、右に国家固有 3 系統（★）を同じ寸法・同じ段で整列。直線と直角のみ、状態は色＋枠線（取得済みは太線、条件不足は点線）＋記号。表示位置の保持、「全体」「選んだ方針へ」。
- **不具合修正**: 画面のドクトリン取得が `doctrineId` を送り、命令側は `id` を読んでいて常に失敗していた（両方受ける）。
- **国家の外交タブ**: 締結できない理由の表示・条約の効果の説明・条約の破棄・制裁・和解の使節。戦争画面: 講和条件に「占領地の割譲」、占領区画の表示、単独講和の説明。
- **世界設定**: 創造主の災厄（確認チェックつき）／ニュースの基準。介入フォームは項目を領域名つきで表示し、関係値は相手の国を選ぶ。
- **地図の重ね**: 河川・交易路・戦線／占領（占領区画の×印）を追加。
