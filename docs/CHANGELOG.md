# 変更履歴

版の決め方: メジャー（2.0.0）は見た目の全面刷新や保存形式が変わる大きな変更／マイナー（2.1.0…）は機能の追加／パッチ（2.0.1…）は不具合の修正。
版の置き場: `package.json` の version、このファイル、git のタグ（`v2.0.0`）、詳細設定の「このアプリについて」（`js/version.js`）。
保存形式の版は、アプリの版とは別に、`.ahmap` の `data.saveFormat` で持つ（旧形式 = 1、条約を導入した形式 = 2）。

## v2.3.0 内戦と検査

- **内戦の決着（機能H）**: 戦争ウィンドウの「内戦の決着」欄（`ui/civil-section.js`）で、選択だけで自動処理する。「鎮圧する」は反乱側の国を解体して属州を元の国へ戻し、「独立を承認する」は反乱側が独立国のまま戦争を終える（`simActions.resolveCivilWar`。講和は条約として残る）。
- **外国の支援**: 国と側（反乱側／元の国側）を選ぶだけで記録できる。条約の一種（`support`）として持ち、戦争が終わると失効する。内戦での参戦招集の対象外トグルは v2.0.0 から外交ウィンドウにある。
- **整合性検査の拡張（機能I）**（`core/edit/records-check.js`、`checkIntegrity` に統合。詳細設定の「データ検査」から実行）: 君主の在位の重なり・すき間、存在しない国への参照（君主・戦争・条約・年表・分離元）、年代が逆転した原因リンク、前身・後継の循環、当事国が消えた条約、期限切れなのに有効のままの条約。

## v2.2.0 世界を詳しく

- **新規作成の統一（機能D）**: 都市・マーカーも、共通の初期設定ウィンドウ（`ui/setup-window.js`）で作る。置く場所（クリック）を決める → 名前・種類を入力 → 確定（確定するまで何も残さない。都市の作成と種類の設定は1回の操作で Undo 1回）。時代の作成は従来の時間・時代区分（詳細設定）のまま、ゾーンは疫病・災害の一時表示（v2.0.0）、同盟は条約として作る。
- **世界情報の詳細化（機能E）**（`core/edit/world-info.js`）: 国の特色（複数選択: 海洋国家・内陸国・遊牧・商業・軍事・学術・宗教国家）、都市の種類（宗教・交易・学術。港・要塞は既存の項目を使う）、属州の称号（辺境伯領・総督領・公領）、資源・特産（鉄・銀・穀物・塩・木材。都市・属州）。すべて選択式で、シミュレーションの数値にはつながず、ホバーカード・詳細・年表の文（「海洋国家の〇〇で…」）にだけ使う。
- **国史（機能F）**（`io/state-history.js`）: 窓は増やさず、年表の「国」「種類」「期間」で絞り、「国史として書き出し（Markdown）」で、君主の一覧・国名の変遷と系譜・主な出来事・原因の流れを自動生成で書き出す。

## v2.1.0 因果と人物

- **出来事の原因リンク（機能A）**: 年表の出来事が「きっかけ」を持つ（`cause`＝`eventKey`）。反乱・独立・宣戦・講和・継承などは、同じ国の近い時期（48か月以内）の出来事へ規則で自動に付く（`core/edit/lineage.js` の `attachCauses`）。手で記録する出来事は `cause` を保存できる。年表の行に「↳ 〜を受けて」、行のホバーに経緯（さかのぼり）、新聞の見出しの下にも同じ文を出す。`cause` の無い古い記録も壊れない。
- **君主と継承（機能B）**: 国ごとに現在の君主と歴代（名前・称号・在位・即位の理由・継承の安定度）を `data.monarchs` に持つ。国家詳細の「操作」から、理由・称号・名前（空なら自動）・安定度を選んで確定（Undo 1回、年表に「〇〇が死去し、△△が即位」）。「大きな混乱」の間は、反乱・独立への入口が出る（自動では起こさない）。
- **国の連続性（機能C）**: 国家詳細に「系譜」の節（前身・後継・国名の変遷・因果の流れ）。分離元（`parentState`）・統合・改名の記録から導く（新しい保存項目はなし）。

## v2.0.0 静かな戦略卓

デザイン仕様の名前を、そのまま版の名前にした。

### 追加・変更
- **見た目の刷新**: 深い炭色と薄い青緑の暗色。見出し・地名は Shippori Mincho、本文は Noto Sans JP、数字は JetBrains Mono。装飾（ノイズ重ね・二重罫線・真鍮の縁取りと角飾り・グラデーション・inset の影）を全廃。絵文字のアイコンを、細線（1.5px・角丸端）の SVG（`js/ui/icons.js`）に置き換えた。地図の配色は変えていない。
- **画面の骨組み**: 上部バー・ステータスバー・凡例サイドバー・ショートカット一覧を廃止。左の収縮式ハブ（`ui/hub.js`、収縮時 56px／展開時 232px、項目16個）、上部中央の小さなフローティング時計、右上の新聞風イベント（`ui/news.js`）、右下の進行中の戦争（`ui/war-status.js`）、地図の隅の小さな表示（地図名・ホバー中のセル・拡大率）。
- **ホバー連動型コネクターライン**（`ui/hover-connector.js`）: 都市・国家（Shift で属州）にカーソルを合わせる（タッチは長押し）と、輪と細い折れ線で概要カードにつなぐ。カードはニュース・戦争状況・時計・ハブ・窓を避けて置く。
- **窓の整理**: 国家（「操作」欄に統合・反乱・独立）・文化・宗教（一覧から系譜図）・属州・外交・戦争・軍事・経済（通貨・為替を統合）・年表・詳細設定（バランス調整・時間と時代区分・データ検査・このアプリについて）。窓は時計の下（上から76px）に開く。
- **条約と外交**（`core/edit/treaties.js`、`ui/diplomacy-window.js`）: 同盟・不可侵・経済協力・従属・国境の画定・共同宣言・講和を、すべて「条約」という一つの部品で持つ。外交ウィンドウは関係一覧（国ごとの条約バッジ）→ 国の条約と履歴 → 条約の中身（改定・破棄）。「条約を結ぶ」は 種類 → 当事国 → 条項 → 名称 → 締結（確定するまで何も残さない）。隠密工作は外交の「工作」欄から。
  - 効果: 同盟は参戦招集（既存の同盟の仕組みに拘束力をつなぐ）、不可侵は宣戦時に警告し、実行すると違約（条約の破棄・民意と信用の低下）、経済協力は当事国間の貿易収入に補正、従属は従属関係と貢納、共同宣言は記録と年表のみ。講和は戦争ウィンドウから結び、締結すると条約一覧に入る。
  - 内戦は、同盟の参戦招集の対象外が既定（外交ウィンドウのトグルで変えられる）。
- **戦争**: 「作戦」欄に核作戦と、戦争の経過を年表で見るリンク。進行中の戦争は右下に（戦争名・両陣営・戦力比・士気・経過月）。新聞風イベントは年表（`io/chronicle.js`）と文面を共通化。
- **疫病・災害のゾーン（一時表示）**: 年表の「＋ 出来事を記録」から、種類・範囲（国全体／属州）・期間を選んで確定。期間の間だけ地図に出て、過ぎたら消える（記録は年表と保存データに残る）。自然発生の疫病にも付く。年表の項目をクリックすると赤い線で強調し、地図がその範囲へ移る。
- **保存形式の版**: `data.saveFormat`。旧形式（1）は読み込み時に条約へ変換し、保存し直すと版 2 になる。

### 廃止
- 旅の機能（旅の線・窓・関連コード）。旅の記録を持つ旧ファイルは壊れずに開け、旅の記録は無視される（保存し直すと消える）。
- ゾーンの一覧・追加・編集の窓。
- 元に戻す・やり直すの画面上のボタン（内部の履歴と transaction、Ctrl+Z / Ctrl+Y は残す）。
- 上部バー、ステータスバー、凡例サイドバー、ショートカット一覧、同盟パネル（条約に統合）、旅・ゾーンの窓。

### まだ入れていないこと
- v2.4.0（国境の年代再生）。文化・宗教の詳細の「系譜」の節も未着手（一覧から系譜図の窓）。`docs/ROADMAP.md` の計画を参照。
- 条約の「領土・国境の画定」は記録のみ（領土の移転は、地図編集の割譲と同じ仕組みを使う想定で、未接続）。
- 条約の期限切れは、表示と宣戦判定では効くが、自動で「失効」に書き換える処理は持たない（整合性検査 v2.3.0 で扱う）。
