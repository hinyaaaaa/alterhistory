# v6 M6〜M8 設計の判断（仕様 §18 の委任事項）

## 介入（M6）
- 方式は全項目 **加算**。有効値 = 通常値 + 残存補正（範囲でクランプ）。介入が無い国の値は、通常値のまま（クランプもしない）。
- 残存補正 = 初期補正 × 0.5^(経過月 / 半減期)。経過月から直接求めるので、保存・復元後も同じ。通常値は介入と無関係に毎期更新される（自己取り込みなし）。
- 項目と既定の半減期（月）: 産業力 36／一人あたり産業力 36（産業力への介入に比例して連動）／交易収入 12／食料の需給 12／財政（税収の倍率）24／装備水準 24／練度 12／正統性 24／疲労度 12。
- 収束の判定: |残存| < max(項目ごとの許容, 初期補正の 0.1%)。収束した介入は記録に残る（状態: 有効・収束・置き換え・取り消し・対象消滅）。
- 介入は `civ.wcde.interventions`（記録）に置き、事実イベントには混ぜない。読み取り用の表 `civ.wcde.adjust` は記録から作る派生データ。
- 因果的に矛盾する値（技術に見合わない産業力など）は拒否せず、自動修復もしない。NaN・Infinity・型違い・範囲外・存在しない対象は拒否。

## 戦争研究所（M7）
- 総合戦力 = 戦力（兵力×軍事能力×防御）×（1−0.3×疲労）×（0.85+0.15×国庫の持久力）。勝率 = ロジスティック(1.6×ln 比) から引き分け確率を除いたもの。
- 不確実性 = 0.12 + 0.35×(1−平均練度) + 0.2×(1−平均安定度) + 国力が小さいほど加算。勝率の幅は、ln 比を ±不確実性 ずらして算出。
- キャッシュは入力の署名をキーにする（入力が変われば使われない）。保存しない。AI の開戦判断（ratio と勝率 ≥ 0.4）も同じ予測を使う。

## 外交交渉（M7）
- 条約の評価（決定的）: 相手から見た関係（v5 の最低線を 0 点）＋恨み＋種類ごとの要因（強弱・交戦中・交易の見込み）＋国内の安定。同盟の同盟国と交戦中・恨みが深いは拒否。同盟が断られても不可侵なら受け入れる場合は、別条件を返す。
- 講和の評価: 戦況（劣勢ほど応じる）＋疲労＋不安定＋国庫の枯渇＋長期化（60 か月で +1）−受け入れの基準（賠償があると上がる）。長く戦えばいずれ応じる。

## ニュースと時間（M8）
- 重大度 = 種類の基礎点 + 15×log2(1 + 関わる国の相対規模)（相対規模 = 人口割合 × 国の数）。85 以上が重大（全画面）、40 以上が主要（右の一覧）。
- 同じ種類・同じ国の重大ニュースは 60 か月は繰り返さない（次は主要に格下げ）。実測: 1,200 か月で重大 10 件（0.1 件/年）。偏り（戦争の終結が 9 件）は今後の調整対象。
- 速度: 停止／1か月/秒／3か月/秒／1年/秒／5年/秒。早送りの管理命令（`time.advance`）はニュースを判定しない。

## 保存（M7）
- 形式 `alterhistory-save` 版 1（アプリの版と独立）。civ の JSON 文字列のチェックサム（64 ビット相当・破損検出用）。地理は設定から再生成し、格子の数を照合する。
- 読み込みは例外を投げず、拒否時は世界を返さない（空の世界に置き換えない）。修復は「派生データの欠落」だけで、診断記録に残す。
