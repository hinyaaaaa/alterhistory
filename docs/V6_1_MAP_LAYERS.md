# 地図のレイヤーと描画（v6.1.1）

## レイヤー（Azgaar 方式）
- 各レイヤーを独立に ON/OFF（`MapView.layers`）。重なり順は `js/ui/v6/map.js` の `LAYERS` の並び（下から上）。
- 塗り: 標高・バイオーム・気温・降水（静的）／人口・宗教・文化・言語・国家（月ごとに変わる）。上に重なるほど手前。塗りは不透明度を変えられる（`MapView.alpha`）。
- 記号・線: 陰影・山岳／河川／国境線／交易路／戦争／戦線／都市／国名／経緯線／区画線。
- プリセット（`PRESETS`）: 政治・文化・言語・宗教・バイオーム・標高・気温・降水・人口交易・軍事・陸地のみ。手動で変えると「カスタム」（どのプリセットにも一致しない）になる。
- 旧 API（`fillLayer` / `overlays`）は廃止。`isOn(id)` / `toggle(id)` / `setPreset(id)`。

## 見た目を自然にする仕組み（`js/ui/v6/terrain.js`）
- 球面の六角形の頂点をゆらし、辺を再帰的に折り曲げる（3 段）。海岸・国境・塗りが同じ辺を共有するので、隙間もずれも出ない。
- 色は連続した階調（標高・水深・気温・降水・人口）とバイオーム固定色。国家・文化・言語・宗教の色は、隣り合うものが似ないよう割り当て（`common.js` の `assignColors`）、一度決めた色は変えない。
- 陰影は北西光源。山・丘の記号は標高から。紙の模様を陸に薄く重ねる。
- 軽さ: 地形・気候・陰影は見ている範囲が変わったときだけ描き直し、画像として保持。ドラッグ・ズーム中は画像を動かすだけで、止まって 110 ms 後に描き直す。

## 地形生成について（変更していない）
- 海岸のゆらぎ項と尾根ノイズを G3 に足す試作では、40 シードの合格率は変わらなかったが、`v520-noise-cache`（v5.1.0 当時の世界との一致）・`v610-m9-core`（開始時代の世界人口の較正）・`v500-world-map`・`v600-m8-ui.smoke` が世界の変化で落ちた。閾値は緩めず、生成側は変更せずに戻した。
- 自然さは描画側（辺の折れ曲がり・色・陰影・山岳記号）で出している。生成を変えるなら、較正（`V6_1_CALIBRATION.md`）をやり直す別作業にする。
